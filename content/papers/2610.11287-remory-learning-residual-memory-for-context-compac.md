## 一句话总结
这篇论文提出了REMORY，一种神经记忆网络，通过生成软记忆标记来增强文本摘要，帮助大型语言模型在有限上下文窗口中近似使用完整历史时的表现。

## 核心问题
长程智能体需要压缩历史记录以适应有限的上下文窗口，但仅使用文本摘要可能无法支持所有后续决策，这限制了模型在长序列任务中的表现。

## 关键方法
1. REMORY生成有界序列的软记忆标记，这些标记基于历史记录和摘要条件化生成。
2. 这些记忆标记被附加在摘要之后，形成序列维度上的残差连接类似物。
3. 网络学习生成能够帮助冻结的大型语言模型近似使用完整历史记录时产生的延续的标记。
4. 保持原始LLM不变，仅添加额外的记忆标记来增强上下文表示。

## 主要结果
1. 在SummHay上，REMORY保持洞察力覆盖率几乎不变的同时显著改善源归属性，仅使用5.2%的输入位置就接近完整上下文性能。
2. 在长程智能体基准测试中，Qwen3.8-27B和GLM-5.3-Flash使用残差 memory 都表现出一致的性能提升。
3. 在BrowseComp和Terminal-Bench 2.1上，两种模型都显著减少了重复工具输出和工具错误。

## 个人看法
REMORY为解决长上下文处理问题提供了创新思路，通过残差记忆机制在保持计算效率的同时保留了更多关键信息。这种方法可能应用于需要长期记忆的对话系统、多轮任务处理和复杂推理场景。然而，该方法可能面临记忆标记选择策略的优化挑战，以及如何在不同任务类型上保持泛化能力的问题。
