## 一句话总结
论文提出了OS-Omni，一个跨平台的计算机使用代理基准测试，用于评估代理在多操作系统环境中执行长期工作流的能力。

## 核心问题
现有基准测试通常将Web、移动或桌面环境隔离，无法评估单一通用代理能否执行跨多个操作系统和持久应用程序状态的长期工作流。这一问题至关重要，因为现实世界的用户任务往往需要跨平台、长时间、保持状态的复杂交互，而当前评估方法无法全面衡量AI代理在这方面的能力。

## 关键方法
1. 创建了OS-Omni基准测试，涵盖Windows、Ubuntu、macOS、iOS、Android和Web六大平台
2. 设计了版本化的任务波次，每波300个任务，首版(v1)包含每平台48个任务和12个跨平台工作流
3. 提供可复现的初始化、平台特定适配器、轨迹记录和可执行最终状态评估器
4. 包含支持账户、购物车、预算、日历、消息等持久状态的服务控制应用程序

## 主要结果
1. OS-Omni任务平均需要67.54个交互步骤，远超OSWorld基准的15.0个步骤
2. 最强评估代理Claude Opus 5.5在v1上达到68.5%的平均成功率，比人类参考(77.3%)低8.8个百分点
3. 模型性能在不同平台上不均衡：在Linux上超越人类，但在iOS和macOS上落后人类超过25个百分点
4. 当前代理在平台鲁棒性、长期计算机使用能力方面仍有很大差距，特别是在需要持续状态跟踪的任务中

## 个人看法
OS-Omni基准测试为评估计算机使用代理提供了更全面、更现实的框架，填补了跨平台长期工作流评估的空白。这项工作对于推动AI代理向更接近人类水平的通用计算机使用能力发展具有重要意义。然而，该基准测试目前仅覆盖了有限的平台组合，未来可以扩展更多跨平台场景。这项研究对于开发真正实用的AI助手具有深远影响，特别是在需要跨设备协作的复杂任务场景中。
