> **作者**: Hanzhang Zhou, Panrong Tong, Xu Zhang, Quyu Kong, Chenglin Cai
> **发布**: 2026-07-30
> **arXiv**: [2607.28227](https://arxiv.org/abs/2607.28227)
> **来源**: hf-daily

## 一句话总结
Qwen-UI-Agent 是一个面向真实世界的基础 GUI 智能体，结合了 GUI 操作与 CLI 执行，在多种平台上实现了最先进的性能。

## 核心问题
论文旨在解决 GUI 智能体在真实世界应用中的可靠性问题，包括跨平台工作流执行、长周期任务完成、主动服务发起以及自主能力提升等挑战，使 GUI 智能体能够成为现有数字设备的通用执行器。

## 关键方法
1. 统一动作空间：将 GUI 操作与 CLI 执行交织在一起，在单个模型回合中生成批量动作，实现更高效的跨平台操作。
2. AutoResearch 数据飞轮：利用智能体自身构建任务和环境、诊断故障并规划后续迭代，形成自我改进的闭环系统。
3. 在线强化学习：支持超过 100 个回合的长轨迹训练，通过 10,000+ 并发环境加速训练过程。
4. 轻量级支撑层：实现跨移动设备和计算机的主动服务发起和有状态工作流。

## 主要结果
1. 移动设备性能：在 MobileWorld 上达到 82.1%，在 MobileWorld-Real 上达到 92.2%，在 AndroidDaily 上达到 97.5%。
2. 计算机使用性能：在 OSWorld-Verified 上达到 79.5%，在 OSWorld-v2 上达到 40.0%的部分进度分数。
3. 浏览器使用和 GUI 定位：在 WebArena 上达到 73.6%，在 ScreenSpot-Pro 上达到 81.5%。
4. 整体表现：在移动使用基准上设置最先进性能，同时在计算机和浏览器使用任务上与前沿模型（包括 Opus 4.8、Gemini 3.1 Pro 和 GPT-5.6 Sol）竞争。

## 个人看法
Qwen-UI-Agent 代表了 GUI 智能体向真实世界应用迈进的重要一步，其统一动作空间和数据飞轮方法为构建自主数字助手提供了新思路。该技术有望在自动化办公、智能家居控制、辅助残障人士使用数字设备等领域产生深远影响。然而，论文中提到的部分性能指标（如 OSWorld-v2 的 40.0% 部分进度分数）仍有提升空间，且在真实世界复杂场景下的鲁棒性和泛化能力仍需进一步验证。未来工作可能需要关注更复杂的多智能体协作以及与物理世界的交互能力。
