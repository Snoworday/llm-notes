## 一句话总结
论文提出了Agent Memory Distillation (AMD)框架，通过分层记忆将大型教师模型的知识传递给小型学生模型，显著提升了小型代理在工具使用任务中的性能。

## 核心问题
小型语言模型难以生成足够的成功轨迹来构建有效的记忆系统，限制了它们在复杂任务中的表现，如何让小型模型能够利用大型模型的知识是一个重要问题。

## 关键方法
- 构建三种互补的记忆类型：Workflow memory(任务级策略)、Subtask memory(中间粒度的行为示例)和Function memory(函数调用约定和常见陷阱)
- Workflow和Subtask记忆在任务开始时主动注入，Function记忆在工具调用错误时被动检索
- 无需训练的框架，直接从教师模型的成功轨迹中提取知识

## 主要结果
- 在三个工具使用基准测试中，平均准确率分别提升27.2%p、11.2%p和3.4%p
- Subtask memory贡献最大增益，教师效果取决于教师能力和学生兼容性
- 4B大小的学生从AMD中获益最多

## 个人看法
这篇论文提供了一种无需训练就能将大型模型知识传递给小型模型的有效方法，对于资源受限环境中的AI应用具有重要价值。潜在应用包括移动设备和边缘计算中的AI助手。局限包括对教师模型的依赖和记忆质量受教师轨迹质量影响。
